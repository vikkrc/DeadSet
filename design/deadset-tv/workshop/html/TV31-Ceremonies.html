Game ceremonies

Each game’s shared scenes, rebuilt on the scene kit: the object, the faces, the held breath, the stamp.

Proposal
Sixteen ceremonies, eleven games
1Built from shared partsEvery ceremony is the scene kit plus one of five shared objects: faces (medallions), cards (that turn), columns (the tally), a stamp, and the game’s etched object on a vellum medallion. Nothing is drawn as a flat CSS shape.
2The object turns, then the stampReveals always follow the same rhythm: lift, a 0.6–0.8 s held breath, turn (700 ms), stamp (Seal). The result is never in the DOM before its time.
3Banners stay bannersSwaps, claims, signs, dig calls and accusations stay as band ribbons (board 30); only Death’s grave in Graverobbers becomes a Full scene.
