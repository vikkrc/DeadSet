Lobby III · All set, the start

A ready table looks different from a waiting one, and the game begins with a ceremony, not a cut.

Proposal
From “all ready” to Night 0, in four frames
1Never a cutToday the lobby cuts straight to “The game begins”. The start is a ceremony: ready → countdown → deal → arch. Each step is skippable by the host after the countdown.
2The countdown can be cancelledUntil 0, a tap on the host’s phone (or a player leaving) cancels it; the disc returns to the count and the band says why (“Bram left the table”).
3Same start, every gameThe deal changes with the game: role cards (Classic, Missions, Exorcism, Midnight, Carnival masks), the place card sealed (Mimic), crews split (Graverobbers), coffins stacked (Coffins), the wheel set at Life (Omen), the first dilemma face down (Mirror), the candles lit (Séance).
